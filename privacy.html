운영자와 이용자

운영자는 이 개인용 비서를 관리하는 개인이며, 현재 봇은 허용된 한 명의 Telegram 계정에만 응답합니다. 개인정보 관련 문의: zayzacks@gmail.com.

처리하는 정보와 목적

  • Telegram 대화 내용과 전달에 필요한 식별 정보: 요청을 이해하고 본인에게 답하기 위해 처리합니다.
  • Gmail: 본인 승인 후 요청할 때에만 전체 기간의 받은메일·보낸메일·보관메일 메타데이터를 최대 10건 검색합니다. 스팸·휴지통·임시보관함, 메일 본문, 첨부파일은 현재 이 기능으로 읽지 않습니다.
  • Google Calendar: 본인이 선택한 개인 캘린더를 읽기 전용으로 조회합니다. 다른 에이전트의 보호된 캘린더는 이 기능의 대상이 아닙니다.
  • 본인이 입력한 할 일·여행·예약 후보·로컬 초안: 개인 계획을 정리하기 위해 서버의 비공개 저장소에 보관할 수 있습니다. 자동 예약 확정이나 일정 수정은 하지 않습니다.
  • 지도·날씨·환율 요청: 사용자가 요청한 장소 검색어, 주소 또는 좌표 및 필요한 조회 조건을 해당 외부 제공자에 보냅니다. 정밀 위치를 기본값으로 사용하지 않습니다.

외부 제공자

답변 생성에는 OpenAI 모델 경로, 메시지 전달에는 Telegram을 사용합니다. 승인된 읽기 요청에는 Google Gmail·Calendar, 지도 조회에는 Google Maps·Naver Maps·Kakao Local·ODSay, 날씨에는 Open-Meteo, 기준환율에는 Frankfurter/ECB가 요청 내용에 따라 관여할 수 있습니다. 각 제공자의 자체 처리에는 해당 제공자의 정책이 적용됩니다. 본 서비스는 광고 판매를 위해 Google 사용자 데이터를 사용하거나 판매하지 않습니다.

Google API 사용자 데이터에는 Google API Services User Data Policy가, Google Maps 기능에는 Google Maps Platform 이용약관 및 Google 개인정보처리방침이 적용됩니다.

저장과 삭제

인증정보와 개인 로컬 상태는 서버의 비공개 경로에 두며 이 공개 사이트에 게시하지 않습니다. 작업 상태와 운영 영수증에는 현재 자동 일괄 삭제 기간이 설정돼 있지 않습니다. Google 장소 검색에서는 Place ID만 최대 24시간 재사용하고, 원래 검색어 대신 키 기반 해시를 캐시 키로 사용합니다. 만료된 캐시 항목은 조회에 사용하지 않으며 다음 캐시 갱신 때 정리합니다. Google 경로 시간·거리는 장기 캐시하지 않습니다. Telegram·Google·OpenAI 등 외부 제공자 측 보존 기간은 각 제공자의 정책을 따릅니다.

삭제나 조회 범위 변경은 위 연락처로 요청할 수 있습니다. Google 계정에서 연결 권한을 철회할 수 있으며, 권한 철회만으로 이미 저장된 로컬 상태가 자동 삭제되지는 않습니다.

보안과 변경

봇 접근은 허용된 Telegram 계정으로 제한하고, API 키·OAuth 토큰은 서버의 비공개 파일에서 관리합니다. 서비스 범위나 데이터 사용이 변경되면 이 문서를 갱신하고 필요한 경우 새 동의를 받습니다.
